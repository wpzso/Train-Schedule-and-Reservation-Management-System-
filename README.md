📖 Project Overview
A robust, centralized Java Desktop Application designed to streamline railway operations, automate ticket pricing, and provide real-time interactive seat reservation workflows for train station administrators and staff.

🎯 Project Objectives
Provide a secure GUI using Java Swing for booking and managing train schedules securely.

Prevent time-conflicts and overbooking through preemptive database validation and live interactive seat maps.

Automate ticket pricing using a deterministic algorithm based on morning and evening departure times.

Implement Role-Based Access Control (RBAC) to provide distinct and secure dashboards for Admins and Staff.

🚀 Phase 3 Implementation (75% Complete)
Functional Modules: Authentication UI, Admin Dashboard (Trains & Schedules Management), and Staff Dashboard (Interactive Seat Map & Bookings).

Architecture: Implemented using a 4-Layer MVC Architecture (Presentation, Business Logic, Data Access, and Database).

Tech Stack: Built completely in Java using Java Swing / AWT for the frontend, and a local embedded SQLite database for storage.

💻 Deployment & Execution
Local Development:
Clone the repository to your local machine.

Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse, or NetBeans).

Ensure the sqlite-jdbc JAR dependency is added to your project's libraries.

Run the main.Main class to start the application.
(Note: The system will automatically generate the train_management.db file and set up all required tables on the first run).
